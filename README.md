# Portafolio de Denis Stanley Espino Morán

Sitio web responsivo construido con HTML, CSS y JavaScript, inspirado en el boceto compartido.

## Archivos
- `index.html`: estructura de la página.
- `styles.css`: diseño adaptable a móviles y computadoras.
- `script.js`: menú móvil, año automático y formulario de contacto.
- `assets/perfil.png`: fotografía de perfil proporcionada.

## Ver el sitio
Abre `index.html` en tu navegador.

## Publicarlo en GitHub Pages
1. Crea un repositorio público en GitHub.
2. Sube todos los archivos y carpetas de este proyecto.
3. En el repositorio, entra en **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, guarda y espera la publicación.
6. GitHub mostrará el enlace público de tu sitio en esa misma sección.

## Antes de publicar
En `script.js`, reemplaza `correo@ejemplo.com` por el correo que deseas utilizar. Para mantener la privacidad, el teléfono y el correo que aparecen en el boceto no se publicaron como datos reales.
